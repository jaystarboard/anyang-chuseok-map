# 추석 연휴 문여는 병원·약국 지도 — 안양시 동안구

2026년 추석 연휴(9.24 목 ~ 9.27 일) 동안 안양시 동안구에서 **문 여는 의료기관·약국 98곳**을 날짜별로 지도에 표시합니다.
동안구보건소 배포 PDF 명단을 파싱해 좌표를 붙인 정적 사이트입니다.

**https://jaystarboard.github.io/anyang-chuseok-map/**

## 기능

- **날짜 탭** — 9.24 / 9.25(추석) / 9.26 / 9.27. 접속일이 연휴 안이면 오늘 날짜가 기본 선택되고, 연휴 전후면 안내 문구와 함께 가장 가까운 날짜를 보여줍니다.
- **지금 영업중** — 오늘 날짜를 보고 있을 때 현재 시각 기준으로 영업중인 곳만 추립니다. `10:00~01:00` 처럼 자정을 넘기는 영업시간도 전날 범위까지 따져서 판정합니다.
- **종류 필터 / 검색** — 응급실·병원·의원·치과·한방·약국, 이름과 주소 검색.
- **내 위치** — 가까운 순 정렬과 거리 표시.
- **상세 팝업** — 4일치 운영시간 표, 전화 걸기, 카카오맵 열기.

## 인증키가 필요 없습니다

좌표는 **빌드 시점에 한 번** 계산해 `data/facilities.json` 에 넣어 두고, 화면은 OpenLayers + OpenStreetMap 타일만 씁니다.
따라서 실행에 카카오/네이버/VWorld API 키가 필요 없고, 공개 저장소에 키를 두지 않아도 됩니다.
GitHub Pages 에 그대로 올라가며 빌드 단계도 없습니다.

## 좌표 정확도

도로명주소를 OpenStreetMap 의 `addr:street` / `addr:housenumber` 태그에 대조해 좌표를 구했습니다.

| 방식 | 건수 | 오차 |
|---|---|---|
| OSM 건물 주소 완전 일치 | 54 | 이름이 같은 OSM POI 와 교차검증한 중앙값 **7m** |
| 같은 도로 앞뒤 번지 선형보간 | 41 | 최근접 기준번지가 Δ25 이내 → 대략 250m 이내 |
| 수동 확정 | 3 | 카카오맵으로 지번 확인 후 랜드마크·도로 중심점 사용 |

보간·수동 확정 항목은 화면에서 **위치 근사** 배지가 붙습니다. 이 경우 핀보다 팝업의 주소·전화번호를 기준으로 삼으세요.

교차검증에 쓴 이름 동일 POI 9건의 오차는 0 / 0 / 6 / 6 / 7 / 7 / 16 / 134 / 169 m 였습니다.

## 데이터 다시 만들기

```bash
pip install pdfplumber
python tools/build_dataset.py "<동안구보건소 배포 PDF>"
```

PDF 표에는 괘선이 있어 `extract_tables()` 로 일자별 컬럼이 그대로 분리됩니다.
`extract_text()` 만 쓰면 `09:00~16:00 10:00~13:00` 이 4일 중 **어느 날인지 복원할 수 없으니** 반드시 표로 읽어야 합니다.

빌드 스크립트는 추출 결과를 PDF 자체의 소계(병의원 50/44/15/29/21, 약국 47/44/13/30/31, 응급실 1)와 대조하고
어긋나면 중단합니다. 좌표는 Overpass API 로 받아 `tools/.osm_addr_cache.json` 에 캐시합니다.
